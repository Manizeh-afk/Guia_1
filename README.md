# Agenda de contactos

Proyecto de práctica de Git.

## Cómo usar

- README.md: contiene la información general del proyecto.
- .gitignore: indica qué archivos Git debe ignorar.
- contactos.txt: guarda los nombres, teléfonos y correos.
- tareas.txt: contiene la lista de tareas pendientes.
- compras.txt: contiene la lista de productos por comprar.
